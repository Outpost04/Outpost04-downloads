## Online co-op

Choose **PLAY → MULTI PLAYER**, host a lobby and share its invite code, or join a listed server. All players should use the latest game version. Internet co-op uses Epic relays; router port forwarding and DMZ are not needed.

**Enter** opens chat. **C** is push-to-talk. Windows may ask for firewall access and macOS may ask for microphone permission; these are operating-system prompts, not a request for your account password.

## Your progress

Progress is stored locally under the game's existing **Mit Spil** identity, separately from installed game versions. Updates do not reset it. These files are not cloud backups.

- Windows: `%APPDATA%/Godot/app_userdata/Mit Spil/`
- macOS: `~/Library/Application Support/Godot/app_userdata/Mit Spil/`

Back up that folder before manually changing local data. Do not upload it in a public issue.
